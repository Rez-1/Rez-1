I build frontend architecture that large teams can keep shipping on: shared component libraries, monorepos, CI/CD pipelines with quality gates, and the TypeScript that holds it together. I've been freelance since 2011, mostly inside Dutch banks and regulated companies, often as tech lead.

### Selected work

- **ABN AMRO (2022–2024), internet banking.** Tech lead of a team split between the Netherlands and India, working in TypeScript with Vue.js and Lit. Shipped four products in two years, including the integration of the new version of iDEAL, the Dutch online payment system. Unblocked the department's Lit component library: my team built the changes and the owning team reviewed them, so changes took one or two weeks instead of months. axe and Lighthouse ran in CI, and every released feature had a WCAG 2.1 review.
- **Vattenfall (2021–2022).** Added server-side rendering to support a server-driven UI in Angular, integrated the frontend with the .NET backend over REST, and moved the codebase to an Nx monorepo.
- **AFM, Dutch Authority for the Financial Markets (2019–2021).** Angular and TypeScript. OpenID Connect authentication with Microsoft Entra ID. Set up the team's workflows, tooling and coding standards from day one.
- **Vattenfall, formerly Nuon (2017–2019), B2B energy portal.** Designed the hourly data structure that lines up gas and electricity usage with invoices. When one customer arrived with 60,000 connections, high-volume customers moved to backend search, filtering and pagination, and the timeouts stopped. Led the upgrade from AngularJS to Angular 7.
- **Rabobank (2017).** Wrote the roadmap from Angular directives to a component architecture, and set up a shared component library across frontend teams.
- **ING (2011–2016).** JavaScript and Node.js against microservice APIs. Built the team's CI/CD pipeline from scratch.
